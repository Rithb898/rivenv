# Domain Glossary

## Workspace

An ownership boundary for RiVenv data. A workspace may represent one person's personal vault or a shared team space.

## Project

An application or service whose configuration and credentials are managed in RiVenv.

## Environment

A deployment or runtime context for a project, such as development, staging, or production.

## Credential

A sensitive value stored for use with an external service or runtime. Credentials include API keys, access tokens, passwords, certificates, and other secret values.

## API key

A credential issued by an external website or service. It may be a personal key or a project-related key and is not limited to a particular provider category. Examples include AI provider keys, payment provider keys, and source-control service keys.

## Environment variable

A named configuration binding intended to be supplied to an application's runtime environment. Its value may be sensitive and is managed as a credential when stored in RiVenv.

## Personal credential

A credential owned for an individual's use and not inherently tied to a project or deployment environment.
